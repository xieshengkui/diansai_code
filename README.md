## 📖 项目简介

本项目整理了 **2024～2026 年** 全国大学生电子设计竞赛（简称"电赛"）的参赛代码、PCB 设计文件、常用模块资料，以及 **1994～2026 年** 的完整赛题汇总。代码基于 **STM32F407** 和 **TI MSPM0G3507** 双平台开发，涵盖自动行驶小车、自行瞄准装置等多个赛题方向。

希望能为参加电赛的同学提供参考，帮助大家快速上手、少走弯路。

| **开发环境** | STM32CubeIDE / TI CCS Theia |

| **功能模块** | 云台瞄准控制、速度/位置双环 PID、底盘运动控制 |

## 💻 软件开发环境

- **STM32 平台**: [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html) + HAL 库
- **MSPM0 平台**: [TI Code Composer Studio Theia](https://www.ti.com/tool/CCSTUDIO) + TI DriverLib + SysConfig
- **PCB 设计**: [立创EDA](https://lceda.cn/)（`.epro` 格式工程文件）
- **AI 视觉**: [嘉楠 K230 SDK](https://github.com/kendryte/k230_sdk)

## ⚡ 快速开始

### STM32 平台（2024 H 题）

1. 安装 [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html)
2. 打开 `2024年电赛H题代码/2024年电赛H题stm32代码/` 目录作为工作空间
3. 编译并下载到立创天空星 STM32F407 开发板

### MSPM0 平台（2024/2025/2026 题目）

1. 安装 [TI CCS Theia](https://www.ti.com/tool/CCSTUDIO)
2. 导入对应年份的 CCS 工程（`empty` 或 `2024_H_TI` 目录）
3. 编译并下载到立创天猛星 MSPM0G3507 开发板

### PCB 设计

使用[立创EDA](https://lceda.cn/)打开 `PCB板文件/` 下的 `.epro` 工程文件即可查看和编辑。

## 🧩 代码架构（以 2026 H 题为例）

代码采用模块化分层架构，各功能模块独立封装，通过 `headfile.h` 统一引用：

```
empty/
├── empty.c                  # 主程序入口
├── empty.syscfg             # TI SysConfig 配置文件
├── Module/
│   ├── headfile/            # 全局头文件引用
│   ├── bluetooth/           # HC-05 蓝牙通信
│   ├── command/             # 串口指令解析
│   ├── delay/               # 延时函数
│   ├── encoder/             # 编码器测速
│   ├── ICM45686/            # IMU 驱动（TDK 官方驱动库 + 自定义封装）
│   ├── K230/                # K230 AI 视觉通信
│   ├── key/                 # 按键扫描
│   ├── menu/                # OLED 多级菜单
│   ├── motor/               # 直流电机驱动
│   ├── OLED/                # OLED 显示驱动 + 字库 + 位图
│   ├── position/            # 位置环 PID 控制
│   ├── question_task/       # 赛题任务状态机
│   ├── stepper/             # 步进电机控制
│   ├── track/               # 轨迹跟踪
│   └── turn/                # 转弯控制
```

### 控制架构

```
上位机 (蓝牙) / K230 (视觉)
        │
        ▼
┌──────────────────┐
│   command 指令解析  │
└────────┬─────────┘
         ▼
┌──────────────────┐
│  question_task    │  ← 赛题任务状态机
│  任务调度          │
└────────┬─────────┘
         ▼
┌──────────────────┐     ┌──────────────┐
│  position 位置环   │◄───│ encoder 编码器 │
│  (外环 PID)       │     └──────────────┘
└────────┬─────────┘     ┌──────────────┐
         ▼               │ ICM45686 IMU │
┌──────────────────┐     └──────────────┘
│  motor 速度环      │
│  (内环 PID)       │
└────────┬─────────┘
         ▼
┌──────────────────┐
│  PWM 输出 → 电机   │
└──────────────────┘
```
